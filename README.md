# Kana Dojo — version web (iPhone)

Appli pour apprendre les hiragana et les katakana, par Kimo Corp.
Ce dépôt ne contient que le **site compilé** (HTML, CSS, JavaScript) ; le code source est privé.

**Installer sur iPhone :** ouvrir le lien dans Safari → Partager → « Sur l'écran d'accueil ».
